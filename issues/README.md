# 📁 Code Quality Warnings & Advisories Archive

This directory stores automated, timestamped Markdown (`.md`) reports of advisory code quality warnings (such as cognitive complexity advisories, naming conventions, and performance optimization suggestions) generated by the **Code Quality Monitor** during CI/CD analysis.

---

### 📄 Report Structure:
- `warnings_YYYY-MM-DD_HH-mm-ss.md` &mdash; Timestamped Markdown report containing warning tables and collapsible before/after remediation blueprints.
- `latest_warnings.md` &mdash; Pointer to the most recent analysis run.

---
*Generated automatically by Code Quality Monitor (Microsoft Roslyn AST Engine).*
