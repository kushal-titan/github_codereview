- **Problem:** Division or modulo by zero detected in 'a / b' (divisor 'b' resolves to 0).
- **Why it matters:** Division or modulo by zero in 'a / b' throws DivideByZeroException at runtime and crashes the execution flow.
- **Action Steps:**
  1. Check that the divisor is not equal to zero before the arithmetic operation.
  1. Return a fallback value or throw a descriptive ArgumentException.

```csharp

// ✅ AFTER:
int b = 0;
int result = b != 0 ? 100 / b : 0;
```
